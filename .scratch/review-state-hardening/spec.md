# 审核状态与文件操作加固

**Status:** completed

**What to build:** 连续作出 review decision 时立即反馈、有序保存，并可可靠撤销；文件移动和恢复固定到一个工作区，权限错误不会被误判为文件不存在。

**Boundaries:** 保持静态 HTTPS、本地处理、photo group 与 movement journal 语义；不引入 GPU 或整体界面重构。

**Verification:** 单元测试覆盖撤销、保存队列、并发操作和异常分类；隔离浏览器数据验证连续审核与既有移动恢复流程。
