# 本地偏好标注与 AI 代理评估

照片分析完成后，点击“本地偏好盲标与评估”。标注保存在当前浏览器的
当前目录会话中，可以下载 JSON；不会改写照片、人工审核、精选或导出名单。
清除浏览器数据前请下载进度。重新选择同一来源并完成分析后，可通过同一导入入口
恢复已下载的标注 JSON；算法和来源身份必须一致。替换现有标注需再次确认，
取消或无效导入不会覆盖当前进度。保存失败会回退并允许重试。

## 从 AI 草稿开始

选择本地 AI 代理标签 JSON。每项必须同时匹配分析源相对路径与 SHA-256；
改名、内容变化或未匹配项不会套用。标签按“不确定 → 被机器折叠的建议保留 → 其他建议保留 → 可选”排序。
逐张确认“必须保留 / 不必保留 / 暂不确定”，同一重要瞬间使用相同编号。
“可选”表示代理认为无需必留，不表示废片，也不会触发文件操作。

导入文件格式：

```json
{
  "version": 1,
  "provenance": "ai-proxy",
  "labels": [{
    "relativePath": "folder/example.jpg",
    "sourceSHA256": "full-sha256-from-the-file",
    "mustKeep": true,
    "momentId": "moment-001",
    "reason": "代表这一独特瞬间",
    "confidence": "medium"
  }]
}
```

`mustKeep` 可为 true、false 或 null（不确定）。真实文件名、照片、标签和逐文件
评估均只保留在本地，不提交仓库或同步 Notion。AI 草稿经真人确认也会保留
“AI 草稿辅助确认”的来源，不能被当成独立盲测。

## 独立人工验收

先使用另外一批 100–300 张进行调参，再从未用于调参的不同拍摄中随机抽取
500–1000 组，选择“独立验收集”并确认盲标条件。开始后冻结算法版本、模式、强度和机器推荐，
标注对话框不显示分数、推荐或中途评估；完成本轮后才显示结果。
不要在标注时参考结果页推荐；无法满足这个条件时不要勾选独立盲标。

必须保留的照片应填写重要瞬间编号。不确定项不计完成。评估区分：

- 精确目标照片召回：必须保留照片中进入机器短名单的比例。
- 重要瞬间召回：每个必留瞬间至少有一张已标注为可用的同瞬间照片进入短名单。
- 可见目标召回：必留照片仍在候选或保护队列的比例；不等于自动短名单召回。
- 被折叠的目标照片：必留却被机器暂不导出的条目。
- 可见数量减少：显示数量差值；不等于实测人工看片量或用时减少。

实际人工看片数量和用时仍需另行观察记录；程序不会编造 70% 的节省。
AI 代理结果、未确定项、少于 500 张、缺瞬间编号或未经独立盲标都不能签核 Stable。
算法或源文件变化后旧研究不会自动套用，但仍可下载历史记录。旧备份缺少独立来源
或筛选设置证明时保守处理，不能据此取得独立盲测签核。

## 复现代理比较（开发测试工具）

准备本地标签后：

```sh
npm run build
CULLER_PROXY_LABELS=/absolute/local-labels.json \
  node scripts/test-real-culler-2.mjs /absolute/source /absolute/report.json
```

脚本只读源文件，在新的临时 Chrome OPFS 中复制标签对应的分析源，运行生产
构建、导入全部标签并冻结评估；不导出照片。运行前后逐文件核对原目录清单、
SHA、大小和修改时间，最后移除隔离照片副本和浏览器配置。报告必须在源目录外。
此工具不是网页运行所需的本地服务，也不验证外部磁盘写入。
