# 本地复核记录（Mac Chrome）

完成分析后，可点击“记录本次复核（仅本地）”。此功能自愿启用，只写浏览器
本地会话，不上传照片、路径或操作。选择“全量查看对照”或“使用推荐”，明确
操作者，开始后可暂停、继续、完成并下载 JSON；下载文件可重新导入恢复。
切目录会暂停旧记录，刷新后也保持暂停，不计算关闭网页期间的时间。

建议先在少量照片上熟悉流程，再选择难度相近的两批做对照；同一批重复操作
有练习效应。全量对照需打开每个可预览组，才能产生描述性比较。人工决定、
已采纳计划和复制仍独立控制，记录不会替你确认照片或执行导出。

记录分别统计前台活跃时间、大图成功打开的独立组、网格缩略图曝光和人工
决定。前台时间不是注意力测量，缩略图曝光不是实际看过；大图计数也不证明
认真检查。后台、其他操作弹窗和繁忙阶段不计时，长时间调度间隙会标记缺口。

只有完整真人对照与真人推荐记录才显示描述性、按组归一化的变化；AI 和自动化
记录不能变成人类证据。记录不能证明两批难度相当，也不能验证照片质量；同批
练习、预先决定和计时缺口均单独提示。不据此自动宣称达到 70% 人工节省。
目前没有真实用户计时数据，正式评估中的人工节省指标仍为空。

保存失败会暂停记录，可先下载内存副本再重试，不阻止正常照片复核。备份恢复
校验结构和来源，运行中的记录恢复为暂停；覆盖同 ID 需明确确认。浏览器清理
会丢失未备份记录。备份含会话标识和组 ID，请自行保管。
